Student Grade Management System 🎓

📌 About the Project

The Student Grade Management System is a beginner-friendly Python project designed to manage student marks and calculate academic performance. It helps calculate average marks and determine grades based on students' scores.

✨ Features

- Enter student marks
- Calculate average marks
- Determine student grades
- Handle invalid inputs using exception handling
- Display student performance

🛠️ Technologies Used

- Python

🎯 Learning Outcomes

Through this project, I practiced Python functions, conditional statements, exception handling, and basic program logic.

🚀 Future Improvements

- Store student records
- Add student search functionality
- Generate student performance reports
